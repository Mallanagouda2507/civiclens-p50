## 2. Manual vs. AI-Generated Code Comparison

### 2.1 Side-by-Side Architectural Code Analysis

#### Example A: Geospatial Haversine Formula Implementation
- **AI-Generated Draft (Raw Output):**
  ```javascript
  // AI Draft: Basic Haversine without input bounds or precision clamping
  function getDistance(lat1, lon1, lat2, lon2) {
    const R = 6371e3;
    const phi1 = lat1 * Math.PI/180;
    const phi2 = lat2 * Math.PI/180;
    const dPhi = (lat2-lat1) * Math.PI/180;
    const dLam = (lon2-lon1) * Math.PI/180;
    const a = Math.sin(dPhi/2)**2 + Math.cos(phi1)*Math.cos(phi2)*Math.sin(dLam/2)**2;
    return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  }
  ```
  *Critique:* Lacks input validation (crashes on `NaN`), produces minute floating-point inaccuracies for identical points ($10^{-12}$ instead of $0.0$), and uses non-standard parameter ordering.

- **Human-Refactored Production Code (`backend/services/ai/geoSpatialService.js`):**
  ```javascript
  // Production Code: Robust GeoJSON array inputs, bounds validation, centimeter precision
  const calculateHaversineDistance = (pointA, pointB) => {
    if (!isValidCoordinates(pointA) || !isValidCoordinates(pointB)) {
      throw new Error('Invalid coordinate format. Expected [longitude, latitude].');
    }
    const [lon1, lat1] = pointA;
    const [lon2, lat2] = pointB;
    if (lon1 === lon2 && lat1 === lat2) return 0.0;

    const R = 6371000;
    const phi1 = (lat1 * Math.PI) / 180;
    const phi2 = (lat2 * Math.PI) / 180;
    const deltaPhi = ((lat2 - lat1) * Math.PI) / 180;
    const deltaLambda = ((lon2 - lon1) * Math.PI) / 180;

    const a = Math.sin(deltaPhi / 2) ** 2 +
      Math.cos(phi1) * Math.cos(phi2) * (Math.sin(deltaLambda / 2) ** 2);
    const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
    return Math.round(R * c * 100) / 100;
  };
  ```
