## 2. Core Lessons Learned Across the SQA Lifecycle

### Lesson 1: AI Accelerates Syntax but Struggles with Mathematical Edge Cases
- **Observation:** AI tools generated functional trigonometry code in seconds, but failed to anticipate floating-point inaccuracies where identical coordinates produced $0.0000000001\text{m}$ instead of $0.0\text{m}$.
- **SQA Takeaway:** AI must never be trusted with unverified mathematical outputs. SQA engineers must author explicit boundary tests targeting domain extremities (polar bounds, zero distances, antimeridian crossings).

### Lesson 2: The "Over-Mocking" Trap in AI-Generated Test Suites
- **Observation:** When asked to write unit tests for complex services, AI models frequently generate "tautological tests" that mock the entire algorithm, testing their own mock rather than application logic.
- **SQA Takeaway:** SQA policies must mandate **integration tests with real computations**. Mocks should be restricted to external I/O boundaries (e.g. database connections or third-party email APIs), never internal algorithmic pipelines.

### Lesson 3: Static Analysis and AI Review are Highly Complementary
- **Observation:** AI reviewers excel at qualitative semantic critique (e.g. identifying missing coordinate bounds), while SonarQube excels at deterministic hygiene (e.g. variable shadowing, cognitive complexity thresholds).
- **SQA Takeaway:** Maximum software quality is achieved not by replacing static linters with LLMs, but by chaining SonarQube static rules as a pre-commit filter before invoking AI-assisted review.

### Lesson 4: Ethical Governance Requires Non-Destructive System Design
- **Observation:** AI algorithms naturally gravitate toward simplifying database operations (e.g., suggesting that duplicate complaints be silently deleted). In municipal civic governance, this would silence citizen voices and conceal infrastructure severity.
- **SQA Takeaway:** SQA in municipal tech must include **ethical quality audits**. Non-destructive clustering (linking duplicates to increment priority) preserves democratic citizen participation.
