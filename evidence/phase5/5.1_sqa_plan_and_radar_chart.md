## 4. Software Quality Assurance Verification Procedures

1. **Pre-Commit Quality Gate:**
   - Static syntax check: `node --check` across all JavaScript modules.
   - Automated unit tests: `npm test` verifying 70/70 passing tests.
2. **Pre-Merge Quality Gate:**
   - Coverage verification: `npm run test:coverage` asserting $\ge 80\%$ line coverage.
   - End-to-End browser verification: headless Selenium WebDriver running 5 core user actions.
3. **Release & Packaging Quality Gate:**
   - Multi-stage Docker container build and syntax verification of `Jenkinsfile` and `sonar-project.properties`.
