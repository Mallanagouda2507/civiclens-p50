## 2. SonarQube Scanner Configuration (`sonar-project.properties`)

```properties
# SonarQube Project Configuration for CivicLens (P50)
sonar.projectKey=civiclens-p50
sonar.projectName=CivicLens Municipal Complaint Portal
sonar.projectVersion=1.0.0

# Source & Test Directories
sonar.sources=backend/controllers,backend/middleware,backend/routes,backend/services,frontend/src
sonar.tests=backend/tests

# Exclusions: dependencies, coverage output, build artifacts, seed scripts
sonar.exclusions=**/node_modules/**,**/dist/**,**/build/**,**/coverage/**,backend/scripts/**,frontend/public/**

# Test Inclusions & Coverage Import
sonar.test.inclusions=backend/tests/**/*.test.js
sonar.javascript.lcov.reportPaths=backend/coverage/lcov.info

# Source Encoding
sonar.sourceEncoding=UTF-8

# Host URL (Default local instance or CI server)
sonar.host.url=http://localhost:9000
```
