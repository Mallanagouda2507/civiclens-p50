## 2. Controlled Experiment: Three Variants of the Same Task

### Task Description
Develop a module that takes two municipal complaints with geographical coordinates `[longitude, latitude]` and text descriptions, determines if they are duplicates based on spatial distance and text similarity, and returns a boolean result with explainable confidence.

---

### Variant A: Zero-Shot Baseline Prompt (Unconstrained)
```text
Prompt:
"Write a JavaScript function to check if two complaints are duplicates using their GPS coordinates and descriptions."
```

- **Generated Output:**
  ```javascript
  function isDuplicate(c1, c2) {
    // Simple distance
    let dx = c1.lng - c2.lng;
    let dy = c1.lat - c2.lat;
    let dist = Math.sqrt(dx*dx + dy*dy);
    
    // Check text
    let sameText = c1.text.toLowerCase() === c2.text.toLowerCase();
    return dist < 0.001 && sameText;
  }
  ```
- **Evaluation & Failure Analysis:**
  - **Fatal Math Flaw:** Used planar Euclidean distance on degrees (`Math.sqrt(dx*dx + dy*dy)`). 1 degree of latitude $\approx 111\text{km}$, meaning `dist < 0.001` equals ~111 meters in latitude but varies wildly in longitude depending on equator distance.
  - **Fatal Text Flaw:** Exact string equality (`===`). Fails completely on paraphrased complaints ("deep pothole" vs "broken road crater").
  - **Verdict:** **UNUSABLE FOR PRODUCTION.**

### Variant B: Few-Shot Constrained Prompt (Rule-Based)
```text
Prompt:
"You are a Node.js engineer. Write a function `checkDuplicate(c1, c2)` in CommonJS.
Use the Haversine formula for distance in meters with Earth radius R = 6371000m.
Distance threshold is 75 meters.
For text similarity, tokenize the text, remove stopwords, and compute word overlap.
Example 1: 'Pothole on road' vs 'Pothole on road' -> 1.0 similarity.
Example 2: 'Water pipe burst' vs 'Streetlight broken' -> 0.0 similarity.
If distance <= 75 and similarity >= 0.6, return { isDuplicate: true }."
```

- **Generated Output:**
  - Implemented the Haversine formula correctly.
  - Tokenized text into arrays and computed simple Set intersection ratio:
    $$\text{Overlap} = \frac{|A \cap B|}{\min(|A|, |B|)}$$
- **Evaluation & Failure Analysis:**
  - **Improvements:** Correct geospatial math and thresholding.
  - **Remaining Limitations:** Simple set overlap ignores term frequency and is vulnerable to false positives when short sentences share a single common noun. Lacks stemmer support (treats "potholes" and "pothole" as completely distinct words).
  - **Verdict:** **FUNCTIONAL PROTOTYPE, BUT LIMITED GENERALIZATION.**

### Variant C: Chain-of-Thought (CoT) Prompt with Mathematical & Architectural Proofs (Selected)
```text
Prompt:
"Role: Senior Geospatial & NLP Algorithm Architect.
Task: Create a production-grade, highly resilient CommonJS module `duplicateDetectorService.js`.

Step 1 (Input Validation & Coordinate Guard):
- Validate [longitude, latitude] arrays: finite numbers, lat within [-90, 90], lon within [-180, 180].

Step 2 (Stage 1 Spatial Pruning):
- Implement spherical geodesic Haversine distance formula:
  d = 2 * R * asin(sqrt(sin^2(dLat/2) + cos(lat1)*cos(lat2)*sin^2(dLon/2)))
  with R = 6,371,000 meters. Round to centimeters.
- Spatial Gate: If distance > 75 meters, IMMEDIATELY return { isDuplicate: false, distance } without running NLP.

Step 3 (Stage 2 Hybrid Text Similarity):
- Preprocessing: lowercase, remove punctuation, strip common English stopwords.
- Apply suffix stemming for civic terms (e.g., 'potholes' -> 'pothol', 'pipelines' -> 'pipe').
- Compute normalized Term Frequency (TF) Cosine Similarity vector angle.
- Compute Jaccard Token Overlap index: |A ∩ B| / |A ∪ B|.
- Hybrid Score = (0.80 * Cosine) + (0.20 * Jaccard).

Step 4 (Explainable Output Schema):
- Return { isDuplicate: boolean, distanceMeters: number, similarityScore: number, matchingKeywords: string[] }.
- Flag duplicate if distance <= 75 AND hybridScore >= 0.60.

Step 5 (Unit Test Verification):
- Ensure identical coordinates yield exactly 0.0 meters.
- Ensure paraphrased pothole reports score >= 0.65."
```

- **Generated Output:**
  - Produced the production-grade implementation currently in `backend/services/ai/duplicateDetectorService.js`.
  - Full coordinate validation, centimeter rounding, normalized TF vector cosine angles, Jaccard overlap, and explainable keyword attribution.
- **Evaluation & Verdict:**
  - **VERIFIED & ADOPTED IN PRODUCTION.**
  - Passes all 18 algorithmic test cases in `tests/aiEngine.test.js` with zero regressions.
