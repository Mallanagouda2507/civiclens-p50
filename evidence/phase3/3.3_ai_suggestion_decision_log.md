## 1. Overview
In a rigorous academic software engineering project, AI-generated recommendations must not be accepted without critical evaluation. This document logs key architectural, algorithmic, and implementation suggestions provided by AI developer tools during CivicLens development, classified into:
- **ACCEPTED:** Adopted directly due to technical soundness and standards alignment.
- **MODIFIED:** Adopted after substantive human refactoring, security tightening, or mathematical correction.
- **REJECTED:** Dismissed due to architectural over-engineering, dependency bloat, security risk, or ethical concerns.

## 2. Decision Log Matrix

| Decision ID | Target Area | AI Suggestion | Category | Human Engineering Evaluation & Final Action |
|---|---|---|:---:|---|
| **DEC-001** | Duplicate NLP Architecture | Deploy an external Python FastAPI microservice running BERT sentence-transformers with a Qdrant vector database. | **REJECTED** | **Rejected due to dependency bloat and RAM overhead.** A Python microservice would require multi-runtime compilation, GPU/heavy RAM (2GB+), and complex inter-service HTTP networking. Replaced with native Node.js TF-IDF + Cosine similarity executing in $<8\text{ms}$ with zero external daemons. |
| **DEC-002** | Duplicate Complaint Policy | Silently delete or drop incoming complaints that are identified as duplicates to conserve database space. | **REJECTED** | **Rejected on ethical and governance grounds.** Deleting citizen complaints silences endorsements and conceals defect frequency. Replaced with non-destructive clustering: linked child complaints increment `duplicateCount` and elevate master ticket urgency. |
| **DEC-003** | Spatial Distance Calculation | Use Euclidean distance formula on raw longitude and latitude coordinates: $\sqrt{\Delta x^2 + \Delta y^2}$. | **REJECTED** | **Rejected for mathematical invalidity.** Planar distance on spherical coordinates causes massive geographic distortion (up to 40% error across longitude lines in India). Replaced with spherical geodesic Haversine distance ($R = 6,371,000\text{m}$). |
| **DEC-004** | Text Similarity Math | Apply standard 2-document Inverse Document Frequency (IDF) formula: $\text{IDF} = \log(N / \text{df})$. | **MODIFIED** | **Modified due to mathematical bug.** When $N=2$ (comparing two complaints), any word appearing in both documents has $\text{df}=2$, causing $\log(2/2) = 0$ and completely zeroing out cosine similarity on true duplicate pairs. Refactored vector calculation to use normalized Term Frequency (TF) cosine angles. |
| **DEC-005** | Geospatial Input Validation | Check if coordinate array has 2 elements without verifying numeric types or boundary ranges. | **MODIFIED** | **Modified for security & robustness.** Malformed inputs (e.g. `[NaN, 95]`) produced `NaN` distance without triggering error handlers. Added `isValidCoordinates()` validating finite numbers and latitude $[-90, 90]$, longitude $[-180, 180]$. |
| **DEC-006** | Synthetic Seed Generator | Generate random worldwide coordinates and generic lorem-ipsum complaint descriptions. | **MODIFIED** | **Modified for municipal realism.** Refactored generator to use Bangalore urban boundary coordinates (`12.90`–`13.05` N, `77.55`–`77.70` E) and realistic civic grievances across real wards (Indiranagar, Koramangala, Malleshwaram). |
| **DEC-007** | Dual-Mode Data Store | Create a unified data abstraction layer that checks MongoDB connection state and switches to an in-memory repository when offline. | **ACCEPTED** | **Accepted.** Elegant decoupling of persistence tier that enables 100% of unit tests and offline evaluators to run without requiring local `mongod` installation. |
| **DEC-008** | Authentication Security | Hash citizen passwords using bcrypt with a minimum of 10 salt rounds and issue signed HS256 JWT tokens with 24-hour expiration. | **ACCEPTED** | **Accepted.** Industry-standard cryptographic hygiene aligning with OWASP A02 recommendations. |
| **DEC-009** | Interactive Map Icons | Render custom Leaflet `divIcon` with dynamic SVG markers and badge counts for duplicate clusters. | **ACCEPTED** | **Accepted.** Provides clear visual differentiation between Open (Red), In Progress (Amber), and Resolved (Green) complaints with duplicate endorsement pills. |
