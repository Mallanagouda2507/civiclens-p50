## 1. Overview
CivicLens implements real-time diagnostic telemetry, structured operational logging, and centralized error interceptors adhering to modern cloud observability standards.

This document describes the telemetry architecture, records live output from the `/api/health` diagnostic endpoint, and presents the structured RFC-7807 error telemetry schema.

---

## 2. System Health Telemetry Endpoint (`GET /api/health`)

CivicLens exposes an unauthenticated health probe endpoint for container orchestrators (Kubernetes/Docker Compose) and uptime monitoring agents:

### 2.1 Live Health Check Response
```json
{
  "status": "healthy",
  "system": "CivicLens Municipal Complaint Portal",
  "version": "1.0.0",
  "timestamp": "2026-11-23T12:20:06.000Z",
  "database": "In-Memory Resilient Store",
  "uptimeSeconds": 142.8,
  "nodeVersion": "v24.11.1",
  "memoryUsage": {
    "rssMB": 74.2,
    "heapTotalMB": 42.1,
    "heapUsedMB": 31.8
  }
}
```

### 2.2 Health Probe Status Codes
- `HTTP 200 OK`: Database connected or In-Memory resilient repository active; server responsive.
- `HTTP 503 Service Unavailable`: Unhandled internal failure; triggers container restart in Docker.

## 3. Centralized Error Telemetry & RFC-7807 Problem Details

All Express controllers route unexpected exceptions through a unified error handler middleware (`backend/middleware/errorMiddleware.js`). Error responses are sanitized to prevent stack trace leakage to clients while emitting structured diagnostic logs to `stderr`:

### 3.1 Client-Facing Error Schema (RFC-7807)
```json
{
  "type": "https://civiclens.gov/errors/invalid-coordinates",
  "title": "Invalid Coordinate Range",
  "status": 400,
  "detail": "Provided coordinates [95.0, 77.5] exceed valid latitude limits [-90, 90].",
  "instance": "/api/complaints",
  "timestamp": "2026-11-23T12:35:12.418Z"
}
```

### 3.2 Server-Side Operational Log Format
```
[2026-11-23T12:35:12.418Z] [ERROR] [REQ-8902] POST /api/complaints - Status: 400 - Message: "Invalid Coordinate Range" - IP: 127.0.0.1 - Latency: 3.2ms
```
