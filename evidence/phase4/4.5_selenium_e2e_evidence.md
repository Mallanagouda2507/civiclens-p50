## 1. Executive Summary
In strict compliance with syllabus ID 4.5 ("Selenium suite using the page-object pattern"), CivicLens implements an automated browser-level End-to-End (E2E) testing framework organized under the **Page-Object Model (POM)** architectural pattern.

This pattern decouples test scripts from low-level DOM selectors by encapsulating page structure, locators, and UI interactions into dedicated Page Object classes (`BasePage`, `SubmitComplaintPage`, `CivicMapPage`).

## 2. Page-Object Model Architecture

```
                    ┌──────────────────────────────┐
                    │          BasePage            │
                    │  (Navigation, Wait, Click,   │
                    │     Type, Window Bounds)     │
                    └──────────────┬───────────────┘
                                   │
                    ┌──────────────┴───────────────┐
                    ▼                              ▼
      ┌───────────────────────────┐  ┌───────────────────────────┐
      │    SubmitComplaintPage    │  │       CivicMapPage        │
      │  (Locators: title, desc,  │  │  (Locators: mapContainer, │
      │   address, submitBtn;     │  │   tilePane, markerPane,   │
      │   Actions: fillForm,      │  │   filterDropdown;         │
      │   submit, getFeedback)    │  │   Actions: isMapRendered) │
      └───────────────────────────┘  └───────────────────────────┘
```

### 2.1 Base Page Class (`tests/selenium/pages/BasePage.js`)
Encapsulates common WebDriver commands, element waits, and URL navigation.

### 2.2 Submit Complaint Page Class (`tests/selenium/pages/SubmitComplaintPage.js`)
Encapsulates form inputs, coordinate selectors, and feedback banner locators:
```javascript
class SubmitComplaintPage extends BasePage {
  constructor(driver, baseUrl) {
    super(driver, baseUrl);
    this.titleInput = By.name('title');
    this.descInput = By.name('description');
    this.addressInput = By.name('address');
    this.submitBtn = By.css('button[type="submit"]');
    this.feedbackAlert = By.css('.bg-emerald-50, .border-emerald-200, [role="alert"]');
  }

  async fillComplaintForm({ title, description, address }) {
    await this.type(this.titleInput, title);
    await this.type(this.descInput, description);
    if (address) await this.type(this.addressInput, address);
  }

  async submit() {
    await this.click(this.submitBtn);
  }

  async getFeedbackText() {
    const alert = await this.waitForElement(this.feedbackAlert, 8000);
    return await alert.getText();
  }
}
```

### 2.3 Civic Map Page Class (`tests/selenium/pages/CivicMapPage.js`)
Encapsulates Leaflet container locators and rendering assertions:
```javascript
class CivicMapPage extends BasePage {
  constructor(driver, baseUrl) {
    super(driver, baseUrl);
    this.mapContainer = By.css('.leaflet-container');
    this.tilePane = By.css('.leaflet-tile-pane');
  }

  async isMapRendered() {
    const container = await this.waitForElement(this.mapContainer);
    const tilePane = await this.waitForElement(this.tilePane);
    return (await container.isDisplayed()) && (tilePane !== null);
  }
}
```
