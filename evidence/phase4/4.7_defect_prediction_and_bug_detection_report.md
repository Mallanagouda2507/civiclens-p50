## 3. Detailed Bug Detection & Root Cause Analysis

### Bug 1: Inverse Document Frequency Zeroing Out True Duplicates
- **Discovered In:** `textSimilarityService.js`
- **Symptom:** Identical complaints about the same pothole yielded a similarity score of $0.00$.
- **Root Cause:** AI scaffolded a standard 2-document IDF equation: $\text{IDF} = \log(N / \text{df})$. When $N=2$ and the term appeared in both documents, $\text{df}=2$, producing $\log(1) = 0$, completely nullifying the vector cosine magnitude.
- **Automated Detection:** Caught by unit test in `tests/aiEngine.test.js`: `should calculate high cosine similarity for semantically identical complaints`.
- **Resolution:** Replaced IDF with normalized Term Frequency (TF) cosine vectors.

### Bug 2: Leaflet React DOM Collapse Bug
- **Discovered In:** `SubmitComplaintPage.jsx`
- **Symptom:** Interactive map container rendered with zero height on initial page navigation.
- **Root Cause:** CSS `.leaflet-container` lacked explicit height bounds during initial flexbox layout calculation in Vite.
- **Automated Detection:** Caught by Selenium WebDriver Action 5: `assert(mapContainer.isDisplayed())`.
- **Resolution:** Added explicit CSS `h-64 sm:h-80` classes and triggered Leaflet `map.invalidateSize()` on mount.

### Bug 3: JSX Curly-Brace Interpolation ReferenceError
- **Discovered In:** `SubmitComplaintPage.jsx`
- **Symptom:** Vite build crashed with `ReferenceError: m is not defined`.
- **Root Cause:** AI emitted LaTeX markup `$\le 75\text{m}$` directly in JSX; React parsed `{m}` as an undefined JavaScript variable.
- **Automated Detection:** Caught by `npm run build` in CI pipeline.
- **Resolution:** Replaced with HTML entity `&le; 75 meters`.
