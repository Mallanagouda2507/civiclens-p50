## 2. Sprint 1: Project Scaffolding, Data Models & Authentication
- **Duration:** Weeks 1–2
- **Committed Velocity:** 8 Story Points (Delivered: 8 SP)

### 2.1 Sprint Planning
- **Goal:** Establish monorepo structure, Mongoose/In-Memory data models, JWT authentication, and RBAC middleware.
- **Backlog Items Selected:** US-01 (Citizen Auth & JWT, 3 SP), US-02 (Staff RBAC, 2 SP), Task: Dual-Mode Persistence Architecture (3 SP).

### 2.2 Representative Daily Standup Notes (Day 5)
- **Developer 1 (Auth):** Completed bcrypt hashing (10 salt rounds) and JWT issuance; writing Supertest suites.
- **Developer 2 (Data Store):** Prototyping `dataStore.js` to decouple MongoDB dependency; in-memory repository passes basic query tests.
- **Blockers:** Windows socket permission blocks when running Supertest. *Resolution:* Ran test runners with required host environment privileges.

### 2.3 Sprint Review & Demo
- **Demonstration:** Successfully demonstrated user registration, login, JWT token issuance, and HTTP 403 enforcement when citizens attempt staff routes.
- **Stakeholder Feedback:** Ensure demo accounts are pre-seeded for easy evaluation.

### 2.4 Sprint Retrospective
- **What Went Well:** AI scaffolding accelerated boilerplate Express auth controllers by 50%.
- **What Could Be Improved:** Prompting for MongoDB schemas occasionally introduced obsolete Mongoose options (`useNewUrlParser`, `useUnifiedTopology`).
- **Action Item:** Create standardized schema validation prompts specifying Mongoose v8+ conventions.

## 3. Sprint 2: Core AI Engines (Haversine GIS & Text Similarity NLP)
- **Duration:** Weeks 3–4
- **Committed Velocity:** 10 Story Points (Delivered: 10 SP)

### 3.1 Sprint Planning
- **Goal:** Implement geodesic Haversine distance math, TF-IDF vectorization, Cosine/Jaccard similarity, and 6-class department routing.
- **Backlog Items Selected:** US-05 (AI Duplicate Detection, 5 SP), US-06 (NLP Department Classifier, 5 SP).

### 3.2 Representative Daily Standup Notes (Day 4)
- **Developer 1 (GIS Math):** Haversine math passes bounds tests; centimeter-level rounding verified.
- **Developer 2 (NLP Engine):** Discovered IDF penalty bug in 2-document corpus where shared terms yielded 0 similarity.
- **Blockers:** Text similarity score for identical paraphrased complaints was too low (0.32). *Resolution:* Refactored to normalized Term Frequency (TF) cosine vectors.

### 3.3 Sprint Review & Demo
- **Demonstration:** Live demo showing 2 complaints within 25 meters ("Deep road pothole" vs "Broken asphalt crater") triggering duplicate detection with 0.73 similarity and explainable keywords `#pothol`, `#asphalt`.
- **Stakeholder Feedback:** Very impressed with keyword explainability. Requested that stray animal complaints be routed to Health & Safety rather than General.

### 3.4 Sprint Retrospective
- **What Went Well:** Pure JavaScript implementation has zero external binary dependencies and executes in $< 8\text{ms}$.
- **What Could Be Improved:** Initial AI suggestions included bulky Python libraries.
- **Action Item:** Keep all algorithmic engines strictly self-contained in CommonJS Node.js modules.
