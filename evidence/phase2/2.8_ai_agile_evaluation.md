### 2.1 Where AI Provided Massive Acceleration
1. **Mathematical Scaffolding:** Implementing the Haversine trigonometric formula with centimeter rounding was accelerated from an estimated 4 hours of manual derivation and testing to 30 minutes of prompt iteration and boundary testing.
2. **Boilerplate CRUD & Route Handlers:** Generating Express routes, Mongoose models, and standard validation handlers was accelerated by over 60%, allowing developers to focus on architectural resilience.
3. **Automated Test Generation:** AI synthesized comprehensive Jest test inputs (including out-of-bounds coordinates, empty token strings, and malformed passwords) that expanded the test suite to 70 tests with zero developer burnout.

## 3. Failure Modes & Hallucination Analysis

During the project, several concrete AI failure modes were observed and systematically mitigated by human engineering oversight:

| AI Failure Mode | Observed Occurrence in CivicLens | Impact if Unchecked | Human Mitigation Applied |
|---|---|---|---|
| **Architectural Over-Engineering** | AI suggested deploying an external Python microservice running BERT transformers for duplicate text matching. | Severe RAM bloat, Python runtime overhead, and complex inter-service HTTP networking. | **Rejected.** Replaced with native Node.js TF-IDF + Cosine similarity executing in $< 8\text{ms}$. |
| **Mathematical Formulation Flaw** | AI applied standard 2-document Inverse Document Frequency (IDF) formula: $\log(2/2) = 0$, causing shared terms to zero out similarity. | Paraphrased complaints about identical potholes scored $0.0$, breaking duplicate clustering. | **Refactored.** Converted vector calculations to normalized Term Frequency (TF) cosine angles. |
| **API Hallucination** | AI suggested using deprecated Mongoose parameters (`useCreateIndex: true`) and obsolete Leaflet options. | Runtime startup warnings and deprecated API crashes. | **Corrected.** Enforced modern Mongoose v8+ and Leaflet v1.9+ syntax conventions. |
| **Underestimation of Frontend State** | AI estimated React Leaflet map integration at only 3 SP, failing to anticipate DOM resize collapsing bugs. | Broken UI layout where map fails to render tiles on initial navigation. | **Consensus Adjustment.** Elevated story points to 5 SP and added `invalidateSize` lifecycle triggers. |

## 4. Proposed Protocol for AI in Agile Software Engineering

Based on the empirical findings from CivicLens, the following **4-Tier Protocol** is recommended for engineering teams adopting AI in Agile:

```
[ Tier 1: Specification & Prompt Constraints ]
  • Provide explicit tech stack bounds (e.g., "Node.js CommonJS, no external Python").
  • Specify non-functional constraints (execution time < 50ms, zero external daemons).
        │
        ▼
[ Tier 2: Human Architectural Review ]
  • Inspect generated code for mathematical correctness and dependency bloat.
  • Verify spatial coordinate bounds and input validation defenses.
        │
        ▼
[ Tier 3: Automated Verification Gate ]
  • Run automated test suites (Jest unit/integration tests).
  • Enforce minimum line coverage targets (CivicLens enforced 80%; achieved 84.25%).
        │
        ▼
[ Tier 4: Living Academic Audit Trail ]
  • Document accepted, modified, and rejected AI suggestions.
  • Maintain verifiable execution logs and honest evidence registries.
```
