## 3. CivicLens Jira Workflow & Issue Schema

### 3.1 Custom Jira Issue Fields
- `CustomField_1001 [GeoJSON_Coordinates]`: String `[Longitude, Latitude]` validated by regex.
- `CustomField_1002 [Municipal_Department]`: Dropdown `ROADS | WATER_SUPPLY | SANITATION | ELECTRICITY | HEALTH_SAFETY | PARKS`.
- `CustomField_1003 [Duplicate_Cluster_Parent]`: Issue Link `is duplicate of` (links child ticket to master).
- `CustomField_1004 [XAI_Attribution_Keywords]`: Multi-select tag field displaying contributing NLP tokens.

### 3.2 State Machine Transition Rules
